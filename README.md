# FastAPI Learning 🚀
## About
This repository documents my step-by-step learning of FastAPI through small, numbered examples. Each folder focuses on a specific backend development concept.

## Topics Covered

1: FastAPI application setup
2: GET and PUT HTTP methods
3: Path parameters
4: Optional query parameters
5: Request bodies using Pydantic BaseModel
6: Data validation and type hints
5: Testing endpoints using Swagger UI
## run commands
python -m pip install fastapi uvicorn
python -m uvicorn main:app --reload
